# Nyam-server

Nyamlog은 개발자가 배포하여 직접 사용하고 주변 사람에게 가볍게 체험을 권할 수 있는 학습용 토이프로젝트입니다. 상용화, 출품, 불특정 다수 대상의 지속적인 서비스 운영은 목표가 아닙니다.

목표는 Spring Boot와 MySQL로 다음 백엔드 기본기를 직접 구현하고 설명할 수 있는 상태를 만드는 것입니다.

- REST API와 계층형 구조
- 관계형 데이터 모델과 Flyway Migration
- 서비스 계층 트랜잭션과 롤백
- 이메일·비밀번호 가입/로그인과 소셜 로그인, 기본 인가
- 사용자별 식사 데이터 격리
- 영양정보 스냅샷과 일일 합계
- 핵심 단위·통합 테스트
- Swagger를 이용한 수동 확인
- 한 개의 개인용 환경에 배포하고 직접 사용하는 경험
- 주변 사람 몇 명의 자발적인 체험과 피드백

완성 기준은 로컬에서 핵심 흐름을 검증하고, 배포 환경에서 개발자와 소수 지인이 실제로 사용해 볼 수 있는 것입니다. 불특정 다수 모집, 상용 운영, 고가용성, 대규모 트래픽, 복잡한 운영 자동화는 목표가 아닙니다.
